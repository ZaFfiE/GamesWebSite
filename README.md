# Pocket Arcade (GamesWebSite)

Static mini-games site (Snake, Minesweeper) with a unified UI, leaderboard, and accessibility improvements. No framework, uses Shoelace Web Components via CDN.

## Component Library

- Shoelace: https://shoelace.style/ (CDN v2.20.1)
- We use buttons, inputs, dialogs, tabs, alerts, skeletons.
- Theme is customized via CSS variables (see `index.html`).

## Run Locally

This is a static site. You can open `index.html` directly or run a local server for correct routing and tests.

```bash
npm install
npx playwright install --with-deps
npm run serve
# open http://localhost:5173
```

Legacy pages (kept for reference): `snake.html`, `minesweeper.html`.

## Main User Scenario

Main scenario: a casual player opens a game (Snake or Minesweeper), plays a round, saves their name in the save dialog, and sees their entry on the leaderboard. The UI shows loading skeletons, validates the form, prevents duplicate submissions while saving, and handles offline errors with a retry option.

States covered:
- Loading (skeletons), Empty (no scores yet), Success (saved/toast), Error (offline or storage failure).
- While saving, the form disables controls to prevent duplicate submissions.

## Data Storage

- LocalStorage key: `pa.scores`.
- API-like functions are embedded in `index.html` (`api.list`, `api.save`, `api.clear`, `api.restore`).
- Sorting: Snake by highest score, Minesweeper by fastest time.

## Tests (E2E)

We use Playwright to verify the visible behavior of the main flow.

```bash
npm install
npx playwright install --with-deps
npm run test:e2e
```

Config: `playwright.config.ts`. The server is auto-started for tests (http-server on 5173).

Included tests:
- tests/e2e/main-scenario.spec.ts: Full Snake flow end-to-end, double submit guarded
- tests/e2e/validation-and-states.spec.ts: Save form validation, empty leaderboard, offline error + retry
- tests/e2e/minesweeper-flow.spec.ts: Minesweeper save flow end-to-end

Mocking / Test control:
- window.AppTest exposes api, sim, getDb, setDb, openSavePreview, and save call counter hooks (wrapSaveCounter/reset/getSaveCallCount).
- Tests switch network modes (normal/slow/offline), clear/restore data, and open Save dialog without relying on actual gameplay to keep tests deterministic.
